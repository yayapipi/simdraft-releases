# Simdraft 下載 · Downloads

[Simdraft（刻刻）](https://www.simtuit.com/simdraft/) 桌面版的安裝檔。這個 repo 只放安裝檔，沒有原始碼。

Installers for the [Simdraft](https://www.simtuit.com/simdraft/) desktop app. This repository holds the installers only, no source code.

## Windows

到 [最新版本](https://github.com/yayapipi/simdraft-releases/releases/latest) 下載 `Simdraft-Setup-<版本>-x64.exe`，打開後照步驟安裝。
裝好後桌面和開始功能表都會有 Simdraft，`.simdraft` 檔也會用它打開。需要 Windows 10 或 11（64 位元）。

安裝檔還沒有數位簽章，第一次執行時 Windows 可能跳出「Windows 已保護您的電腦」：點「其他資訊」，再按「仍要執行」。
不想安裝的話，下載 `Simdraft-<版本>-win-x64.zip`，解壓縮後執行裡面的 `Simdraft.exe`。

Download `Simdraft-Setup-<version>-x64.exe` from the [latest release](https://github.com/yayapipi/simdraft-releases/releases/latest)
and run it. Simdraft then sits on your desktop and in the Start menu, and opens `.simdraft` files. Windows 10 or 11, 64-bit.
The installer is not code-signed yet, so Windows may say "Windows protected your PC" the first time: click "More info",
then "Run anyway". To skip the install, take `Simdraft-<version>-win-x64.zip`, unzip it and run `Simdraft.exe`.
